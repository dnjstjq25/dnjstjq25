## Currently Building

### Portfolio Site

개발 경험과 프로젝트의 결과만 나열하지 않고,  
**어떤 문제를 맡았고 어떻게 구조를 나누어 해결했는지**를 읽을 수 있는 포트폴리오를 만들고 있습니다.

`Next.js` `React` `TypeScript` `Tailwind CSS` `MDX`

### Green Wallet

수입·지출 기록, 월별 흐름, 카테고리별 소비를 확인하기 위한 **개인용 가계부 서비스**입니다.  
제가 계속 사용하는 것을 전제로 화면과 기능을 개선하고 있으며, 거래 내역의 자동 분류도 실험하고 있습니다.

`React` `TypeScript` `Vite` `Spring Boot` `Java` `MariaDB`

### Korea Signal Watcher

국내 주식 후보를 수집하고 기술적 신호를 기록하며,  
전략 결과를 백테스트와 페이퍼 트레이딩으로 검증하는 **조회·분석 전용 도구**입니다.

실제 주문은 수행하지 않으며, 후보 선정 기준과 진입·재진입 조건을 데이터로 검토하는 데 집중하고 있습니다.

`Python` `Pandas` `KRX / KIS API` `CSV Pipeline` `Backtesting`

### Football Data Content Pipeline

축구 경기 데이터를 수집·정리하고 주요 지표와 시각화 자료를 생성해  
경기 리뷰와 콘텐츠 제작에 활용하기 위한 데이터 파이프라인입니다.

현재는 FotMob 데이터를 중심으로 수집 범위를 단순화하고,  
아스날 경기 데이터를 반복적으로 처리할 수 있는 구조를 만들고 있습니다.

`Python` `Pandas` `Matplotlib` `FotMob Data`

### DOKGOO Web Games

짧게 플레이할 수 있지만 상황과 연출에서 기억에 남는 웹 게임을 실험하고 있습니다.

- **DOKGOO Company** — 마감 직전의 회사 프로젝트를 배경으로 한 선택형 픽셀 RPG
- **퇴근확률 0.1%** — 직장인의 퇴근을 슬롯머신으로 표현한 웹 미니게임

`JavaScript` `React` `Canvas / Web UI` `Pixel Art Assets`

## How I Work

```text
문제를 크게 설명하기
      ↓
지금 필요한 최소 범위로 줄이기
      ↓
화면 · API · 데이터 구조 분리
      ↓
직접 실행하고 사용해 보기
      ↓
불편한 부분을 다시 개선하기
```

- 새로운 도구를 만드는 것보다 기존 도구로 더 단순하게 해결할 수 있는지 먼저 확인합니다.
- 기능이 동작하는 것에서 끝내지 않고 이후 수정과 운영이 가능한 구조인지 함께 봅니다.
- 생성된 코드를 그대로 사용하기보다 실제 흐름과 예외 상황을 확인합니다.
- 결정된 내용과 남은 작업을 문서로 정리해 다음 작업의 시작 비용을 줄입니다.
